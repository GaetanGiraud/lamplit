the real build with a real browser (`npm run screenshots`), so if one of them looks out of date,
it is out of date and worth an issue.

## The shape of the thing, in one paragraph

A **story** holds who tells it, who you play, and its world. A story has **chapters**, and a
chapter is the conversation plus the **scene** it opens on and the **summary** it closes with.
Only the chapter you are writing is ever sent to the model; earlier chapters reach it through
**the story so far**, which "close chapter" rewrites. Everything is one JSON file per document,
saved as you type, and the whole prompt is rebuilt from those documents on every request.

## Conventions in these pages

- **Bold** names a thing you can click.
- Paths like `data/stories/<id>.json` are relative to wherever the app is running from.
- Where a page says "the app insists", it means exactly one thing: a sheet that will not take
  Escape for an answer. There are only two in the whole app.
